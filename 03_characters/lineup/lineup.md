# Size Lineup

Confirms relative heights so every page keeps the characters at a consistent scale. Updated 2026-10-19 for the v1.0 cast.

**Target:** Mom about 2× Milo → Milo = Noah → Boris (sitting) about Milo's knee-to-waist.

## Approach
Build the lineup in **GIMP** from the locked turnaround front views, scaling each figure:

| Character | Relative height (Milo = 100%) |
|---|---|
| Mom | ~200% |
| Milo | 100% |
| Noah | 100% |
| Boris (sitting) | ~35% |

Draw a faint horizontal guideline at each head height. Also mark each character's **glow center** (the heart, center of the chest) and **glow diameter** (about 1.5× chest width, bible §5.4) on this sheet, so the glow lands in the same place on every page. Save as `lineup_LOCKED.png`.

## Use in Gate 6
Drop the lineup onto a hidden layer when compositing each page and scale every figure to match it.
